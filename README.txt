ALTEA — GLOBUS

Gotowy statyczny prototyp.

Mapa źródłowa: 2048×1078 px.
Do globusa utworzono kopię 2156×1078 px (dokładnie 2:1) przez dodanie 54px oceanu z lewej i 54px z prawej. Nie rozciągano mapy.

NAJSZYBSZA PUBLIKACJA — GITHUB PAGES
1. Utwórz nowe PUBLICZNE repozytorium na GitHub, np. altea-globus.
2. Wrzuć do głównego katalogu plik index.html z tego folderu.
3. Wejdź w Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: main, folder: / (root), Save.
6. Po chwili GitHub pokaże publiczny adres strony.

UWAGA
- index.html jest samowystarczalny: mapa jest osadzona bezpośrednio w pliku.
- Do działania potrzebuje internetu, bo silnik Three.js jest ładowany z CDN.
- Shift + klik na globusie pokazuje współrzędne mapy — przyda się później do dodawania pinów.
- Nie umieszczaj w kodzie sekretnego lore: wszystko zawarte w publicznej stronie może zostać podejrzane przez graczy.
